# practica-2-programacion-avanzada
# 🎬 Sistema de Reservas de Cine

practrica para la materia de Programación - BUAP  
Permite a los usuarios seleccionar películas, funciones, asientos y confirmar sus boletos.  
Además, cuenta con un módulo administrador para agregar o eliminar películas y promociones.

---

## 💻 Requisitos
- Python 3.10+
- Librería `customtkinter`
- Librería `Pillow`

Instalar dependencias:
```bash
pip install customtkinter pillow

▶️ ¿Cómo ejecutar?
Desde una terminal dentro de la carpeta del proyecto:
--- python main.py


🧩 Funcionalidades principales
-Catálogo de películas con imagen
-Selección de función y asientos disponibles
-Confirmación de reserva
-Panel de administración:
-Agregar / eliminar películas
-Agregar / eliminar promociones
